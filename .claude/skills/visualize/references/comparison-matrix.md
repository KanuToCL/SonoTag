# Comparison Matrix

A structured side-by-side format for evaluating options, vendors, approaches, or tools against defined criteria. Decision-oriented, evidence-based, winner-clear.

---

## When to Use

Detect this archetype when:
- User mentions "compare", "comparison", "matrix", "evaluation", or "decision"
- Content evaluates 2-4 options against multiple criteria
- User needs to make or recommend a choice between alternatives
- There is a "which should we use?" or "what are the trade-offs?" question
- Options need to be scored, ranked, or assessed against each other
- A recommendation with supporting evidence is expected

---

## Communication Goal

A comparison matrix communicates structured evaluation that makes the right choice feel inevitable rather than arbitrary. The reader should immediately see which option is recommended, understand the criteria that drove the decision, and trust the analysis because it honestly presents both strengths and weaknesses of every option. The structure itself is the argument.

---

## Layout DNA

The page opens with a header stating what is being compared and why, followed immediately by a summary block that delivers the recommendation upfront with a confidence level. The core of the page is the comparison table: criteria as rows, options as columns, with visual scoring (filled dots, color-coded ratings, or progress bars) in each cell. The recommended option receives a subtle but unmistakable visual distinction (a highlighted column header, a badge, or a colored border). For 2 options, a side-by-side "versus" layout works well with each option occupying half the width. For 3-4 options, a full matrix table is clearer. Below the matrix, detailed breakdowns for each option provide context, trade-offs, and evidence that the scoring reflects.

---

## Interaction DNA

The comparison matrix is primarily a scanning surface. The reader's eyes move across rows, comparing scores horizontally, then drop down to the next criterion. Visual scoring (dots, bars, color) makes this horizontal comparison instant without reading any text. The recommended option's visual distinction pulls the eye like a magnet, creating a natural anchor point. For detailed views, tabs or collapsible sections let readers drill into individual options without losing the overview. Hover states on score indicators can reveal the reasoning behind a particular rating.

## Flavor Seeds

**Boxing Tale of the Tape** — Two fighters standing on opposite sides of the ring, their stats printed in the program: height, reach, weight, record, knockout percentage. The side-by-side layout makes comparison physical and visceral. Split down the middle, contrasting colors for each corner, numbers that tell you who should win before the bell rings.

**Wine Tasting Scorecard** — A sommelier's comparative tasting notes: four glasses lined up, each scored on nose, palate, finish, value. Spider charts for each wine overlaid on the same axes, revealing different flavor profiles as geometric shapes. Cream paper, elegant serif type, dots filled in with fountain pen ink. The winner circled with a confident flourish.

**Car Spec Sheet** — The comparison page in a car magazine: three vehicles photographed from the same angle, a grid of specs below (horsepower, torque, 0-60, price, fuel economy). The editor's pick gets a gold badge. Every number is tabular-aligned for instant scanning. The format is so standardized that readers can compare without reading any prose.

**Scientific Peer Review Rubric** — A grant committee's evaluation matrix: proposals scored across innovation, feasibility, team capability, broader impact. Each criterion weighted, scores averaged, top proposal highlighted in green. Clinical, rigorous, every judgment transparent and traceable. The structure removes subjectivity from the process.

**Restaurant Health Inspection Card** — The letter grade posted in the window tells you the verdict before you read a single line item. Below it, the detailed scoring: food temperature, cleanliness, storage, pest control. Green checks and red X marks. The hierarchy is verdict first, evidence second. Everyone can read it in 5 seconds.

## CDN Dependencies

None required. This archetype relies on table structure and visual scoring, achievable with pure markup and styling.

---

## Anti-Patterns

- Don't present options without defining evaluation criteria first. "Which is better?" needs "better at what?" answered explicitly.
- Don't give the favored option more detail or visual real estate than others. Asymmetric presentation implies bias and undermines trust.
- Don't use more than 8-10 criteria without grouping. Too many rows makes the matrix unreadable; group related criteria under headers.
- Don't rely on text-only scoring like "Good" vs "Fair." Use visual scales (dots, bars, colors) that are scannable at a glance.
- Don't omit an overall recommendation. The entire purpose of a comparison is to help someone decide; leaving it open-ended wastes the reader's time.
- Don't compare things that are not in the same category. Apples-to-oranges comparisons erode credibility even when the format is rigorous.
- Don't hide trade-offs of the recommended option. Showing weaknesses of the winner builds more trust than a perfect score on every criterion.
